Section 2.0

Module 8: Functional Scope & Architecture Breakdown (BA Ref: ARCH-001)

Full Specification Mapping

Derived directly from ARCH-001: Technical Architecture & Hardware Infrastructure Blueprint, the implementation scope is structured across 5 core technical pillars:

2.1 On-Premises 3-Tier Server Virtualization & Database Clustering
  • Proxmox VE / KVM Virtualization: Deployment of isolated Virtual Machines for Web/App layer, Database layer, and Background DAEMON services.
  • Database High Availability: MariaDB replication cluster with automated failover and daily point-in-time recovery (PITR) snapshots.
  • Nginx Reverse Proxy & Load Balancer: SSL termination, HTTP/2 compression, request throttling, and DDoS protection filters.
  • Automated Local & Cloud Backup Pipeline: AES-256 encrypted night-time database dumps and transaction log sync to remote off-site storage.
2.2 Android PDA Handheld Barcode / QR Scanner Integration (DAEMONs)
  • Handheld Hardware Compatibility: Integration with Honeywell, Zebra, and Urovo industrial Android rugged PDA barcode scanners.
  • Low-Latency REST/WebSocket DAEMON: Sub-second verification of scanned PCodes, bin locations, and purchase order items.
  • Offline Buffer Mode: Local SQLite caching on handhelds ensuring warehouse picking and stock taking proceed during Wi-Fi blind spots.
  • Handheld Device Management: Device authorization tokens, remote configuration push, and scanner battery telemetry monitoring.
2.3 ESC/POS POS Thermal Receipt & Zebra Industrial Barcode Label Printing
  • Direct Network ESC/POS Driver: Raw socket printing to Epson/Bixolon 80mm POS thermal receipt printers bypassing browser print dialogs.
  • Zebra Programming Language (ZPL) Engine: High-speed dynamic generation of 2D QR and Code-128 barcode shelf tags and item labels.
  • Multi-Terminal Print Spooler: Centralized queue management handling concurrent receipt prints across all checkout counters without collision.
  • VAT-Compliant Invoice Layouts: Dynamic printing of NBR-compliant simplified VAT tax invoice receipts with embedded cryptographic QR codes.
2.4 Multi-Branch Biometric Attendance Device Gateway (ZKTeco Protocol)
  • ZKTeco Standalone Push Protocol: Gateway service capturing live biometric clock-in / clock-out punches from branch attendance terminals.
  • Device User Synchronization: Automated two-way enrollment push of staff biometric IDs, names, and card numbers to all branch terminals.
  • Heartbeat Health Monitor: Real-time status ping tracking online/offline connectivity of biometric clocks across all retail branches.
2.5 Network Security, SSL/TLS Encryption & Automated SAN Backup Vault
  • End-to-End SSL/TLS Encryption: HTTPS certificates deployed across all local intranet endpoints and mobile device endpoints.
  • VLAN Network Segmentation: Segregation of POS terminals, server cluster, Wi-Fi handhelds, and guest networks via managed switches.
  • Automated SAN Backup Vault: Nightly differential and weekly full backup archives with automatic 30-day retention pruning.
